
# AI Automation Platform

An AI-powered automation platform designed to reduce
manual work and improve operational efficiency in
admissions and real estate businesses.

## Initial Focus Areas

### 1. Admissions Automation
Automate repetitive tasks in educational institutions:
- Student enquiry management
- Lead follow-ups
- Admission eligibility checks
- Application status tracking
- Automated communication

### 2. Real Estate Automation
Automate repetitive tasks for real estate businesses:
- Property enquiry management
- Lead qualification
- Customer follow-ups
- Property recommendations
- Site visit scheduling

## Technology Stack

- Backend: Node.js
- Language: JavaScript / Python (to be evaluated)
- AI: LLM APIs
- Database: PostgreSQL (planned)
- Version Control: Git and GitHub

## Project Goals

1. Identify repetitive business workflows.
2. Validate real-world problems with potential customers.
3. Build useful AI-powered automation workflows.
4. Develop a scalable platform.
